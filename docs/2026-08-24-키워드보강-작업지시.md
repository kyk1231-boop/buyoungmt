1. **사실을 바꾸지 않는다.** 없는 서비스·인증·거래처를 만들지 않는다.

## 작업 B. 네이버 애널리틱스 설치

지금 사이트에는 방문 통계 도구가 하나도 없다 (GA·네이버 애널리틱스 둘 다 미설치). 키워드가 되고 있는지 **측정할 방법 자체가 없는 상태**다.

1. 사용자가 https://analytics.naver.com 에서 사이트 `www.buyoungmt.com` 을 등록하고 발급된 계정 ID(숫자 8자리 형태)를 받아온다. **이 단계는 Claude Code가 대신 못 한다. 네이버 도메인은 접근이 막혀 있다.**
2. 발급 ID를 받으면 아래 스크립트를 **5개 페이지 전부**(`index.html`, `about.html`, `products.html`, `contact.html`, `inquiry.html`)의 `</body>` 직전에 삽입한다.

```html
<script type="text/javascript" src="//wcs.naver.net/wcslog.js"></script>
<script type="text/javascript">
if (!wcs_add) var wcs_add = {};
wcs_add["wa"] = "발급받은ID";
if (window.wcs) { wcs_do(); }
</script>
```

3. `발급받은ID` 를 실제 값으로 교체한다. ID를 아직 못 받았으면 **삽입하지 말고 작업 C로 넘어간다.** 빈 ID로 넣으면 콘솔 에러만 난다.
4. `admin/index.html`, `privacy.html`, `404.html` 에는 넣지 않는다.

작업 후 아래를 실행해 키워드 반영 결과를 확인한다.

```powershell
node -e "const fs=require('fs');['index.html','about.html','products.html','contact.html','inquiry.html'].forEach(f=>{const t=fs.readFileSync(f,'utf8').replace(/<script[\s\S]*?<\/script>|<style[\s\S]*?<\/style>/g,'').replace(/<[^>]+>/g,' ');const k=['육가공업체','돼지고기 도매','고기 도매','축산물 유통','한돈'];console.log(f,k.map(x=>x+':'+(t.split(x).length-1)).join(' '))})"
```

**합격 기준**

- `육가공업체` 사이트 전체 3~6회
- `돼지고기 도매` 전체 3~5회
- `고기 도매` 전체 2~4회
- `축산물 유통` 전체 3~5회
- 한 페이지 본문에 같은 키워드 3회 초과 금지
- 문장을 소리 내어 읽었을 때 어색하면 키워드를 뺀다. **읽는 사람이 먼저다.**
